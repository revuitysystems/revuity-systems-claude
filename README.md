# Revuity Systems Claude Plugin

Official Claude plugin for Revuity Systems AI Environments and the Revuity Systems MCP.

This plugin connects Claude to the client-facing Revuity Systems MCP so authorized Revuity clients can work with the AI Environment Revuity has designed and maintains for their business.

## What it provides

- Access to the client’s Revuity-managed AI Environment
- Workflows, roles, skills, and environment context
- Installation and update plans
- Connection requirements
- Support and change requests
- Outcomes, reviews, and other entitled delivery information

## MCP endpoint

https://oosccskpcxhfueuhtmtf.supabase.co/functions/v1/revuity-mcp

Authentication is required through Revuity OAuth. Access is tenant-scoped and tied to an authorized Revuity MCP seat.
